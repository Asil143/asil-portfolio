# LinkedIn Profile Alignment

This file captures public-safe positioning guidance from the LinkedIn profile audit shared with the repository.

## Primary Goal

The website and LinkedIn profile should make a recruiter conclude quickly:

"This person builds modern cloud data platforms."

Avoid positioning that reads like:
- A student portfolio
- A data analyst trying to become a data engineer
- A profile built around coursework instead of production data engineering

## Headline Direction

Recommended headline style:

Senior Data Engineer | Python • SQL • PySpark • Apache Spark • Databricks • Snowflake | AWS • Azure | Kafka • Airflow • dbt | Lakehouse • Streaming

Alternative compact style:

Senior Data Engineer | Databricks • PySpark • Apache Spark • Python • SQL | Snowflake • Airflow • dbt • Kafka | AWS • Azure | Lakehouse • Streaming

Keep the headline focused on cloud data engineering, not broad software development or analytics.

## Intro / Top Card Checklist

LinkedIn should align with:

- Current company: Publicis Sapient
- Current title: Senior Data Engineer
- Industry: IT Services and IT Consulting
- Professional location: San Diego, California, United States, if this is the intended public location

Make sure older education or older employers do not become the primary top-card identity.

## Activity / Writing Strategy

Original technical posts should reinforce the same expertise as the site:

- Medallion Architecture
- CDC vs batch ingestion
- Star schema vs snowflake schema
- Server vs serverless data engineering
- Monolith vs loosely coupled pipelines
- Delta Lake vs Apache Iceberg
- Spark performance tuning
- Kafka streaming patterns
- Airflow/dbt orchestration
- Data quality and DataOps
- Partitioning tradeoffs

The goal is for profile visitors to see evidence of data engineering judgment, not only a list of keywords.

## Positioning Caution

Use "Senior Data Engineer" only where it is supported by approved resume history. Do not manufacture seniority, years of experience, metrics, or responsibilities.

If there is uncertainty between "Data Engineer" and "Senior Data Engineer" for a public claim, ask before changing the site or LinkedIn copy.
